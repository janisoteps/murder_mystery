# Season 2 external image-generation pack — *The Ninth Bell*

These prompts are deliberately spoiler-safe. They contain appearance, architecture, atmosphere, and public role only. Do not add clues, injuries, documents, readable signage, symbolic foreshadowing, or unexplained figures.

## Consistency workflow

1. Generate the two investigators first.
2. Choose one result for each and reuse those images as identity references if your service supports references.
3. Use the shared portrait block for every character, changing only the subject block.
4. Use the shared location block for every exterior/interior.
5. Save the selected images using the exact paths listed below. PNG is preferred for portraits and locations.
6. Generate no text inside any image. The browser supplies labels.
